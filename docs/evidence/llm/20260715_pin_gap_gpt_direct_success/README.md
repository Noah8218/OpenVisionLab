## Reproduce

Run from the repository root:

```powershell
dotnet build "OpenVisionLab.sln" -c Debug -p:Platform="Any CPU"

.\bin\Debug\OpenVisionLab.exe --smoke llm-xml-draft-file `
  --draft .\docs\evidence\llm\20260715_pin_gap_gpt_direct_success\response.xml `
  --output .\artifacts\llm_evidence_replay\validate_import

.\bin\Debug\OpenVisionLab.exe --smoke llm-xml-image-run `
  --draft .\docs\evidence\llm\20260715_pin_gap_gpt_direct_success\response.xml `
  --image .\docs\samples\public\Line_Pins_Synthetic_OK.png `
  --output .\artifacts\llm_evidence_replay\nominal

.\bin\Debug\OpenVisionLab.exe --smoke llm-xml-image-run `
  --draft .\docs\evidence\llm\20260715_pin_gap_gpt_direct_success\response.xml `
  --image .\docs\samples\public\Line_Pins_Synthetic_WidePin_NG.png `
  --output .\artifacts\llm_evidence_replay\negative_expected_ng
```

Expected results:

- Validation/import: PASS; XML syntax and deserialization OK; 9 Steps; 0 errors; 0 warnings; import completed; `ImageRun: SKIPPED`.
- Nominal image: PASS, 9/9 Steps; `DistanceMmAvg=0.151..0.159`; `DistanceMmRange=0.006..0.012`.
- Negative image: expected product NG at Step 1; `DistanceMmAvg 0.116 < 0.14`. Its smoke report uses `Result: FAIL` because the inspection correctly rejected the image while XML validation remained successful.

Validation/import and each image execution are separate explicit actions. Publishing this package does not add automatic Preview/Run, create layers, or change recipe routing.
