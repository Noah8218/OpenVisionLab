## Reproduce

Run from the repository root. The commands build first, then replay the tracked package with the latest Debug EXE.

```powershell
dotnet build "OpenVisionLab.sln" -c Debug -p:Platform="Any CPU"

$repo = (Resolve-Path .).Path
$exe = Join-Path $repo "bin\Debug\OpenVisionLab.exe"
$package = Join-Path $repo "docs\evidence\llm\20260716_morphology_cleanup_gpt_direct_success"
$evidence = Join-Path $repo "artifacts\morphology_gpt_evidence_replay"

& $exe --smoke llm-xml-draft-file `
    --draft (Join-Path $package "response.xml") `
    --output (Join-Path $evidence "validate_import")
if ($LASTEXITCODE -ne 0) { throw "Validation/import replay failed." }

& $exe --smoke llm-xml-image-run `
    --draft (Join-Path $package "response.xml") `
    --image (Join-Path $repo "docs\samples\public\Morphology_Cleanup_Synthetic_OK.png") `
    --expect-run-success true `
    --output (Join-Path $evidence "nominal")
if ($LASTEXITCODE -ne 0) { throw "Nominal replay failed." }

& $exe --smoke llm-xml-image-run `
    --draft (Join-Path $package "response.xml") `
    --image (Join-Path $repo "docs\samples\public\Morphology_Cleanup_Synthetic_Missing_NG.png") `
    --expect-run-success false `
    --output (Join-Path $evidence "negative_expected_ng")
if ($LASTEXITCODE -ne 0) { throw "Expected NG replay did not match." }
```

Expected results:

- Validation/import: PASS; 3 Steps; 0 errors; 0 warnings; `ImageRun: SKIPPED`.
- Nominal: PASS; `ResultCount=4` within the `4..4` gate.
- Missing-target negative: expected product NG; `ResultCount=2 < 4`.
- Both replay input images retain `3 -> 1 -> 1` channel transitions. The negative command returns 0 only because `--expect-run-success false` declares the expected product rejection.

Validation/import and image execution remain separate explicit actions. This evidence package does not add automatic Preview/Run, create layers, or change layer-routing behavior.
