## Reproduce

Run from the repository root. The helper waits for the latest built EXE and verifies the expected process exit code.

```powershell
dotnet build "OpenVisionLab.sln" -c Debug -p:Platform="Any CPU"

$repo = (Resolve-Path .).Path
$exe = (Resolve-Path ".\bin\Debug\OpenVisionLab.exe").Path
$package = Join-Path $repo "docs\evidence\llm\20260716_edge_fiducial_gpt_direct_success"
$evidence = Join-Path $repo "artifacts\edge_fiducial_evidence_replay"

function Invoke-OpenVisionSmoke {
    param(
        [string[]]$Arguments,
        [int]$ExpectedExitCode = 0
    )

    $process = Start-Process -FilePath $exe `
        -ArgumentList $Arguments `
        -WorkingDirectory (Split-Path $exe) `
        -WindowStyle Hidden `
        -Wait `
        -PassThru

    if ($process.ExitCode -ne $ExpectedExitCode) {
        throw "Expected exit code $ExpectedExitCode, got $($process.ExitCode)."
    }
}

Invoke-OpenVisionSmoke -Arguments @(
    "--smoke", "llm-xml-draft-file",
    "--draft", (Join-Path $package "response.xml"),
    "--output", (Join-Path $evidence "validate_import")
)

Invoke-OpenVisionSmoke -Arguments @(
    "--smoke", "llm-xml-image-run",
    "--draft", (Join-Path $package "response.xml"),
    "--image", (Join-Path $repo "docs\samples\public\Edge_Fiducial_Synthetic_OK.png"),
    "--output", (Join-Path $evidence "nominal")
)

Invoke-OpenVisionSmoke -ExpectedExitCode 1 -Arguments @(
    "--smoke", "llm-xml-image-run",
    "--draft", (Join-Path $package "response.xml"),
    "--image", (Join-Path $repo "docs\samples\public\Edge_Fiducial_Synthetic_Wrong_NG.png"),
    "--output", (Join-Path $evidence "negative_expected_ng")
)
```

Expected results:

- Validation/import: PASS; 1 Step; 0 errors; 0 warnings; both template dependencies copied; `ImageRun: SKIPPED`.
- Nominal: PASS; `ResultCount=1`; `ScoreMin/Max/Avg=99.598`; overlay count 1.
- Wrong-shape negative: expected product NG; validation remains successful; `ResultCount=0`; `BestScore=61.052`; overlay count 0.
- The negative command returns exit code 1 because the smoke runner represents the correct inspection rejection as a failed image-run command.
