# OpenVisionLab CVR-00 참가자 과제지

날짜: 2026-07-29 KST

## 참가자 안내

이 평가는 OpenVisionLab을 처음 사용하는 사람이 제품 안의 정보만으로
검사 흐름을 이해할 수 있는지 확인합니다. 참가자의 능력을 평가하는 시험이
아닙니다.

- 작업하는 동안 보고 있는 것과 다음에 할 것이라고 생각하는 내용을
  소리 내어 말해 주십시오.
- 확신이 없으면 추측해서 진행해도 됩니다.
- 진행자에게 안전 관련 질문은 언제든지 할 수 있습니다.
- 막혔거나 화면의 의미를 이해하지 못했으면 그대로 말해 주십시오.
- 외부 설명서, 검색, 이전 화면 캡처는 사용하지 마십시오.

화면 이름, 버튼 이름, 정답 수치, 예상 결과는 이 과제지에서 제공하지
않습니다. 제품 안의 안내와 증거를 사용하십시오.

## 과제 A — 한 쌍의 검사 샘플 이해하기

다음 공개 샘플을 사용합니다.

- `Public_Blob_Particles_Good`
- `Public_Blob_Particles_Sparse_Bad`

제품 안에서 다음 목표를 순서대로 완료하십시오.

1. 두 샘플이 무엇을 검사하며 Good과 Bad가 어떻게 다른지 설명하십시오.
2. Good 샘플의 검사 Recipe를 찾아 한 번 실행하십시오.
3. 최종 OK/NG 판단을 화면의 도면 한 가지와 수치 기준 한 가지로
   설명하십시오.
4. 검출된 객체 중 허용된 객체 하나와 제외된 객체 하나를 찾아, 표 또는
   도면을 근거로 두 상태가 다른 이유를 설명하십시오.
5. 이 검사에서 Blob 설정을 어디에서 배우고 어디에서 수정하는지
   찾으십시오. 설정을 실제로 바꾸지는 마십시오.
6. Recipe의 시작 요약 화면으로 돌아가 다음에 실행할 수 있는 작업을
   설명하십시오.

## 과제 B — 여러 이미지 검증과 증거 보존

진행자가 준비한 임시 복제 Recipe를 사용합니다.

1. 여러 이미지의 예상 결과와 실제 결과를 비교하는 기능을 찾으십시오.
2. 위 Good/Bad 샘플을 각각 올바른 예상 역할로 등록하고 검증을
   실행하십시오.
3. 저장된 실행 결과에서 한 행을 선택하고 다음 네 가지를 구분하여
   설명하십시오.
   - 예상 결과
   - 실제 결과
   - 판정의 정답 여부
   - 실행 오류
4. 현재 검증 결과를 고정된 증거로 보존하려면 무엇이 더 필요한지
   설명하십시오.
5. 가능한 경우 임시 고정 증거를 만들고 검증한 뒤 작업용 복사본을
   만드십시오.
6. 작업용 복사본이 원래의 고정 증거와 동일한 자격을 갖는지
   설명하십시오.

## 종료 질문

1. 검사 실행을 실제로 발생시키는 동작과 단순히 화면을 이동하거나
   선택하는 동작은 무엇이 달랐습니까?
2. 한 이미지의 OK/NG 결과와 여러 이미지의 검증 결과는 무엇이
   달랐습니까?
3. 가장 먼저 막힌 지점 또는 가장 이해하기 어려웠던 표현은
   무엇이었습니까?
4. 다시 같은 검사를 만든다면 반복하지 않고 저장되어 있기를 바라는
   설정은 무엇입니까?

진행자가 요청하기 전에는 이 과제지에 정답이나 개선안을 작성하지
마십시오.
