## Close Rule

- `Closed`: 구현과 비가시 검증 또는 화면 검증이 완료된 항목.
- `Closed / Watch`: 기능은 완료되었고, 실제 사용자 사용 중 문제 발견 시에만 재오픈할 항목.
- `Reopen Condition`: 이 조건이 발생할 때만 다시 작업 대상으로 올린다.

## Explicitly Not Closed

아래 항목은 완료 문서로 올리지 않는다.

- 전체 UI 시각 마감: 기능별 UI는 많이 개선되었지만 모든 화면의 최종 visual polish는 끝난 것이 아니다.
- 모든 Tool별 NG/OK sample pair: 주요 sample은 있지만 모든 검사/결함군을 대표하지는 않는다.
- LLM Recipe 완전 자동 tuning: safe fix 기반은 있지만 모든 파라미터를 자동 보정하는 수준은 아니다.
- 외부 라이브러리 version/package 정책: 참조 구조는 정리했지만 배포 정책은 최종 확정 전이다.
- DockPanel visual layout Undo/Redo: 레이어 생성/삭제 자체는 1차 완료했지만, float/dock 위치까지 pixel-level로 되돌리는 범위는 아직 포함하지 않는다.
