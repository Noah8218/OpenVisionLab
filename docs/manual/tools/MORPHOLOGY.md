# Morphology: 작은 노이즈 제거와 영역 연결

## 목적과 준비

Threshold 결과의 작은 흰 점을 제거하거나 끊어진 영역을 연결할 때 사용합니다.
가능하면 이진 Layer를 입력으로 사용합니다.

## 순서

1. Threshold Preview에서 제거할 점 또는 연결할 틈을 확인합니다.
2. 왼쪽 `모폴로지`를 엽니다.
3. 입력을 `Threshold_Preview`, 출력을 `Morphology_Preview`로 둡니다.
4. 작업을 선택합니다: Open, Close, Erode, Dilate.
5. Kernel 모양과 크기를 작은 값부터 설정합니다.
6. 반복 횟수를 1부터 시작합니다.
7. `미리보기 실행`을 누릅니다.
8. 원래 대상의 크기와 개수가 유지되는지 확인합니다.
9. Blob/Contour를 뒤에 연결해 실제 개수 변화를 확인합니다.
10. 결과가 맞으면 저장합니다.

## 선택 기준

- Open: 작은 흰 노이즈 제거
- Close: 작은 검은 구멍이나 끊김 연결
- Erode: 흰 영역 축소
- Dilate: 흰 영역 확대

## 실패 확인 순서

입력 이진 방향 -> 작업 종류 -> Kernel -> 반복 횟수 순서로 확인합니다. 숫자가
맞아도 서로 다른 대상이 붙으면 완료가 아닙니다.
