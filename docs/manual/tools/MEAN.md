# Mean: 평균 밝기 판정

## 목적과 준비

한 ROI의 평균 밝기와 범위를 비교해 밝음/어두움, 누락, 오염 같은 차이를
단순하게 판정할 때 사용합니다.

## 순서

1. 밝기를 측정할 물리 영역을 정합니다.
2. 왼쪽 `평균`을 엽니다.
3. 입력 Layer와 결과 Layer를 확인합니다.
4. Mean 방식과 채널을 선택합니다.
5. ROI를 대상 안쪽에 설정합니다.
6. Good 여러 장의 `MeanValueAvg`와 범위를 먼저 기록합니다.
7. 정상 최소/최대 범위를 설정합니다.
8. `미리보기 실행`을 누릅니다.
9. ROI 드로잉과 평균/범위 Metric을 확인합니다.
10. Bad에서 같은 ROI와 기준이 밖으로 나가는지 확인 후 저장합니다.

## 실패 확인 순서

입력 Layer -> ROI 위치 -> 채널/Mean 방식 -> 조명 변화 -> 기준 범위 순서로
확인합니다. ROI가 배경이나 반사를 포함하면 평균값이 검사 의도를 설명하지
못할 수 있습니다.
