# Contour: 외곽선과 형상 후보

## 목적과 준비

이진 영역의 외곽선을 찾고 면적, bounds, 각도 같은 형상 정보를 비교할 때
사용합니다. 단순 연결 영역 개수는 Blob이 더 직접적입니다.

## 순서

1. 찾을 외곽 경계와 내부 구멍 필요 여부를 정합니다.
2. 왼쪽 `컨투어`를 엽니다.
3. 입력/출력 Layer를 확인합니다.
4. Threshold 방향과 값을 설정합니다.
5. Retrieval mode와 Approximation 방식을 선택합니다.
6. ROI와 Min/Max Area를 설정합니다.
7. 필요할 때 Width/Height 범위를 설정합니다.
8. 컨투어 표시 방식, 색상, 두께를 설정합니다.
9. `미리보기 실행`을 누릅니다.
10. 실제 대상 외곽을 따라가는지 확인합니다.
11. accepted/rejected row와 `ResultCount`를 확인합니다.
12. Good/Bad에서 같은 형상 의미를 유지할 때 저장합니다.

## 실패 확인 순서

입력 이진 방향 -> ROI -> Retrieval -> Area/크기 -> 약한 경계 -> 표시 방식 순서로
확인합니다. 작은 픽셀 노이즈가 모두 object row에 나오지 않을 수 있습니다.
