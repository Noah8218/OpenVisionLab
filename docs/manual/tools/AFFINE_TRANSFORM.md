# Affine Transform: 세 점 기준 좌표 정규화

## 목적과 준비

서로 일직선이 아닌 세 물리 점의 대응으로 회전, 이동, 균일/비균일 scale,
shear를 포함한 2D 변환을 만들 때 사용합니다. 세 점의 물리적 동일성과 순서를
작업자가 책임집니다.

## 순서

1. 안정적이고 서로 떨어진 Source 점 3개를 정합니다.
2. 같은 물리 특징의 Destination 점 3개를 같은 순서로 정합니다.
3. 왼쪽 `어파인 변환`을 엽니다.
4. 입력/출력 Layer와 출력 크기를 설정합니다.
5. Source/Destination 좌표 3쌍을 입력합니다.
6. 삼각형 면적과 최소 유효 픽셀 gate를 설정합니다.
7. 필요할 때만 앞 Step의 검출 Point 참조를 켭니다.
8. `미리보기 실행`을 누릅니다.
9. Source/Destination 삼각형, 변환 프레임, 2x3 행렬을 확인합니다.
10. 유효 픽셀 비율과 잘림을 확인합니다.
11. 정규화 출력에서 downstream 고정 ROI를 가르칩니다.
12. 같은 세 locator와 Affine을 한 Run에서 실행하도록 저장합니다.

## 실패 확인 순서

점 순서 -> 중복/일직선 점 -> 좌표 범위 -> 출력 크기 -> 유효 픽셀 -> locator
성공/모호성 순서로 확인합니다. Homography나 카메라 교정을 의미하지 않습니다.
