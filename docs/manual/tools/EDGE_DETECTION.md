# Edge Detection: 경계선 찾기

## 목적과 준비

밝기 변화가 큰 경계를 영상으로 만들거나 Line/형상 검사의 선행 결과를 확인할
때 사용합니다. 약한 텍스처가 많은 영상은 Filter를 먼저 검토합니다.

## 순서

1. 찾을 물리 경계와 방향을 정합니다.
2. 왼쪽 `엣지 검출`을 엽니다.
3. 입력과 `Edge_Preview` 출력 Layer를 확인합니다.
4. Canny, Sobel, Scharr, Laplacian 중 목적에 맞는 방식을 선택합니다.
5. 낮은/높은 임계값 또는 Kernel을 설정합니다.
6. 방해 영역을 제외할 ROI를 설정합니다.
7. `미리보기 실행`을 누릅니다.
8. edge가 실제 물리 경계 위에 이어지는지 확인합니다.
9. 배경 텍스처와 노이즈 edge가 과도하지 않은지 봅니다.
10. downstream Tool이 같은 경계를 사용하는지 확인 후 저장합니다.

## 실패 확인 순서

입력 대비 -> ROI -> 방식 -> 낮은/높은 임계값 -> Filter 순서로 확인합니다.
edge 픽셀이 많다는 이유만으로 성공으로 판단하지 않습니다.
