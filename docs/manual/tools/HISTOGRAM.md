# Histogram: 밝기 분포와 대비 확인

## 목적과 준비

영상이나 ROI의 밝기 분포, 평균, 대비를 비교하고 평활화 효과를 확인할 때
사용합니다. 단일 평균 판정만 필요하면 Mean이 더 단순합니다.

## 순서

1. 확인할 이미지와 ROI를 정합니다.
2. 왼쪽 `히스토그램`을 엽니다.
3. 입력과 별도 출력 Layer를 확인합니다.
4. 분석할 채널 또는 gray 방식을 선택합니다.
5. 평활화, CLAHE, normalize 옵션은 하나씩 적용합니다.
6. `미리보기 실행`을 누릅니다.
7. 원본/결과 평균과 대비가 어떻게 변했는지 봅니다.
8. 어두운/밝은 끝에 값이 몰려 포화되지 않았는지 확인합니다.
9. downstream Threshold나 Matching 결과도 함께 비교합니다.
10. 효과가 반복 샘플에서 유지될 때 저장합니다.

## 실패 확인 순서

입력 채널 -> ROI -> 처리 방식 -> clip/grid/normalize 옵션 순서로 확인합니다.
분포 변화가 커도 검사 대상의 경계나 특징이 사라지면 사용하지 않습니다.
