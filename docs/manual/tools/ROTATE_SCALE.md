# Rotate / Scale: 회전과 크기 정규화

## 목적과 준비

알고 있는 각도와 배율로 이미지를 변환하거나 다음 Step의 기준 좌표를 만들 때
사용합니다. 자동 위치 검출이나 카메라 교정 기능은 아닙니다.

## 순서

1. 회전 중심과 원하는 출력 크기를 정합니다.
2. 왼쪽 `회전 / 스케일`을 엽니다.
3. 입력 Layer와 별도 출력 Layer를 선택합니다.
4. Angle을 설정합니다.
5. X/Y scale을 설정합니다.
6. 출력 크기와 border 채움 방식을 확인합니다.
7. `미리보기 실행`을 누릅니다.
8. 대상이 잘리거나 빈 border가 검사 ROI에 들어오지 않는지 봅니다.
9. 다음 Tool ROI가 변환된 대상 위에 있는지 확인합니다.
10. 고정 변환으로 충분할 때만 Pipeline에 저장합니다.

## 실패 확인 순서

각도 부호 -> 회전 중심 -> X/Y scale -> 출력 크기 -> border -> downstream ROI
순서로 확인합니다. 이미지마다 위치가 달라지면 고정 Rotate/Scale만 반복 조정하지
말고 검증된 locator/fixture가 필요한지 검토합니다.
