# HSV: 색 범위 분리

## 목적과 준비

밝기만으로 나누기 어려운 색 영역을 Hue, Saturation, Value 범위로 선택할 때
사용합니다. 조명이 바뀌면 색 범위도 달라질 수 있으므로 여러 샘플이 필요합니다.

## 순서

1. 선택할 색과 제외할 색을 정합니다.
2. 왼쪽 `HSV`를 엽니다.
3. 입력과 `HSV_Preview` 출력 Layer를 확인합니다.
4. Hue 범위를 좁게 시작합니다.
5. Saturation과 Value 최소/최대 범위를 설정합니다.
6. 필요한 경우 ROI와 mask 옵션을 설정합니다.
7. `미리보기 실행`을 누릅니다.
8. 선택 mask가 실제 색 영역 위에 있는지 확인합니다.
9. 선택 픽셀 비율과 색 분포를 확인합니다.
10. Good/Bad와 조명 변화 샘플에 같은 범위를 실행한 뒤 저장합니다.

## 실패 확인 순서

입력 색 채널 -> Hue wrap 범위 -> Saturation -> Value -> ROI -> 조명 변화 순서로
확인합니다. 회색/저채도 영역은 Hue가 안정적이지 않을 수 있습니다.
