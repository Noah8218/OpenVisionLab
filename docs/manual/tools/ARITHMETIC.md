# Arithmetic: 두 Layer 합성·차이·논리 연산

## 목적과 준비

두 이미지나 마스크를 더하거나 빼고, AND/OR/XOR 같은 논리 연산을 수행할 때
사용합니다. Layer A와 B의 크기와 좌표 의미가 같아야 합니다.

## 순서

1. 비교하거나 합성할 두 Layer를 준비합니다.
2. 왼쪽 `산술 연산`을 엽니다.
3. 입력 Layer A와 입력 Layer B를 명시적으로 선택합니다.
4. 별도 출력 Layer를 지정합니다.
5. Add, Subtract, Multiply, Divide 또는 bitwise 연산을 선택합니다.
6. 계수나 오프셋이 있으면 기본값에서 시작합니다.
7. `미리보기 실행`을 누릅니다.
8. 두 Layer가 같은 위치에 정렬됐는지 확인합니다.
9. 값이 0 또는 최대값으로 포화되지 않았는지 봅니다.
10. 결과를 다음 Tool 입력으로 쓸 때 route를 저장합니다.

## 실패 확인 순서

Layer A/B 선택 -> 이미지 크기 -> 좌표 정렬 -> 연산 방향 -> 계수/오프셋 순서로
확인합니다. Subtract는 A-B와 B-A가 다릅니다.
