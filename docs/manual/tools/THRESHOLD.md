# Threshold: 밝고 어두운 영역 분리

## 목적과 준비

대상과 배경의 밝기 차이를 흑백 이미지로 분리할 때 사용합니다. 입력은 보통
`Main`, 출력은 `Threshold_Preview`입니다. 색 자체가 기준이면 HSV를 먼저
검토합니다.

## 순서

1. 이미지의 대상과 배경 중 어느 쪽을 흰색으로 만들지 정합니다.
2. 왼쪽 `스레시홀드`를 엽니다.
3. 입력 `Main`, 출력 `Threshold_Preview`를 확인합니다.
4. 처음에는 `기본` preset을 선택합니다.
5. `Binary` 또는 `BinaryInv` 방향을 선택합니다.
6. 기준값과 Max 값을 설정합니다.
7. 필요한 영역만 볼 때 ROI를 설정합니다.
8. `미리보기 실행`을 누릅니다.
9. 흰 대상이 끊기지 않고 배경 노이즈가 적은지 확인합니다.
10. 맞으면 `파이프라인에 추가·저장`을 누릅니다.

## 확인할 결과

- 출력 흑백 방향
- 대상 내부의 구멍과 끊김
- 배경의 흰 노이즈
- ROI 위치와 출력 Layer

## 실패 확인 순서

입력 Layer -> Binary 방향 -> 기준값 -> ROI -> 적응형 옵션 순서로 확인합니다.
조명 차이가 큰 경우에만 적응형 Threshold를 검토합니다. Good 하나에 맞춘 뒤
Bad와 다른 Good에서도 같은 값을 실행합니다.
