# 결과 근거와 한계

## 결과를 승인하기 전

다음 네 가지가 같은 대상을 설명해야 합니다.

1. 입력 이미지와 ROI
2. 결과 드로잉
3. Metric
4. Good/Bad 또는 Validation 결과

실행 횟수나 `OK` 글자만으로 결과를 승인하지 않습니다.

## 단위

- px 결과는 이미지 좌표의 픽셀 결과입니다.
- mm 결과는 적용된 `mm per pixel` 값에 의존합니다.
- 두 점 scale은 한 이미지 평면의 균일 scale이며 카메라 교정이 아닙니다.
- 왜곡, 원근, 깊이 변화가 있으면 별도 물리 검증이 필요합니다.

## 범위

이 프로그램은 샘플 이미지 기반 규칙 작성, 실행, 비교, 검증을 위한
워크벤치입니다. 카메라, 조명, PLC, I/O, MES, 생산 제어, 현장 성능 인증을
이 매뉴얼이 보증하지 않습니다.

LLM Assistant는 선택적인 XML 작성 보조 기능입니다. 기본 작업 흐름이나
매뉴얼 완료에 필요하지 않습니다.
