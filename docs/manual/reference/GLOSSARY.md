# 화면 용어

| 용어 | 뜻 |
| --- | --- |
| Image | 검사할 사진 |
| Main | 원본 이미지의 기본 Layer |
| Layer | 원본 또는 중간/최종 결과 이미지 |
| ROI | 검사할 이미지 영역 |
| Tool | 한 가지 처리나 검사를 수행하는 기능 |
| PropertyGrid | Tool 파라미터 편집 표 |
| Preview | 현재 Tool 설정을 한 번 시험하는 명시적 실행 |
| Step | Pipeline에 저장된 Tool 한 단계 |
| Pipeline | Step을 실행 순서와 Layer route로 연결한 목록 |
| Recipe | Pipeline과 Tool 설정의 저장 단위 |
| Metric | ResultCount, Area, Score, Distance 같은 판정 숫자 |
| Drawing/Overlay | 대상 위의 box, 선, 중심, ROI 표시 |
| Run Review | 저장된 Pipeline을 명시적으로 실행하고 Step별 결과를 검토하는 기능 |
| Good/Bad | 정상/비정상 비교 역할. 실행 성공/실패와는 다름 |
| WAIT | 아직 이번 실행 결과가 없는 정상 대기 상태 |
