# 이미지·공개 샘플·Layer 준비

## 이미지 여는 방법

- `이미지 로드`: 내 이미지 한 장을 현재 작업의 `Main`에 엽니다.
- `샘플 열기`: 설명, Good/Bad 쌍, 기준, 준비된 Pipeline이 있는 공개 샘플을 엽니다.

처음 배우는 경우 공개 샘플을 먼저 사용합니다. 내 이미지는 검사 목표, ROI,
정상 범위가 정해진 뒤 사용합니다.

## Layer 기본 규칙

- `Main`: 원본 이미지입니다.
- 결과 Layer: Tool Preview나 Pipeline Step이 만든 이미지입니다.
- Tool의 입력 Layer는 작업할 이미지를 정합니다.
- 출력 Layer는 결과를 보존할 위치입니다.
- 출력 Layer를 만들거나 선택해도 Tool의 입력은 자동으로 바뀌지 않습니다.

## 순서

1. 이미지 또는 공개 샘플을 엽니다.
2. 중앙 viewer의 현재 Layer 이름과 이미지 크기를 확인합니다.
3. 원본은 `Main`에 남깁니다.
4. Tool을 열고 입력 Layer를 명시적으로 선택합니다.
5. 출력 Layer는 용도를 알 수 있게 지정합니다. 예: `Threshold_Preview`.
6. Preview 후 `Main`과 출력 Layer를 비교합니다.
7. Layer를 삭제하거나 이름을 바꾸기 전에 사용하는 Pipeline Step이 없는지 봅니다.

## ROI

ROI는 검사할 영역입니다. 전체 이미지에서 먼저 결과를 확인한 뒤 방해 대상이
있을 때 ROI를 좁힙니다. ROI가 너무 작으면 정상 대상이 잘리고, 너무 크면
다른 물체가 결과에 들어옵니다.

## 완료 확인

- 현재 이미지와 Layer 이름을 말할 수 있습니다.
- Tool이 읽는 Layer와 쓰는 Layer가 다릅니다.
- 원본 `Main`이 보존됩니다.
