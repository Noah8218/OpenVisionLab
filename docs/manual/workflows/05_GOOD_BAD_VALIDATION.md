# Good/Bad 샘플로 같은 규칙 검증

## 원칙

Good과 Bad에 서로 다른 값을 맞추지 않습니다. 한 번 저장한 같은 Pipeline과
같은 기준을 두 이미지에 실행해 Metric이 의도한 이유로 갈리는지 확인합니다.

## 순서

1. Good 샘플을 엽니다.
2. Pipeline Review에서 `Run Review`를 누릅니다.
3. 각 Step 드로잉과 Metric을 확인합니다.
4. Good이 기준 안에 들어오는 이유를 적습니다.
5. `짝 샘플` 또는 `NG 기준 열기`로 Bad를 엽니다.
6. 설정을 바꾸지 않고 같은 Pipeline으로 `Run Review`를 누릅니다.
7. Bad의 첫 NG Step을 선택합니다.
8. 입력 Layer, 드로잉, Metric, reject 이유를 확인합니다.
9. Bad가 기준 밖으로 나가는 이유를 적습니다.
10. 숫자만 우연히 갈린 경우 ROI나 대상 선택을 먼저 고칩니다.

## 구분

- `검증 OK`: Pipeline 정의와 입력이 실행 가능한 상태
- `결과 OK`: 검사 Metric이 저장된 정상 범위 안
- `결과 NG`: 검사 Metric이 정상 범위 밖
- `오류`: 입력, 의존 파일, 파라미터 또는 실행 문제가 있음

## 완료 확인

- Good과 Bad가 같은 대상과 같은 좌표 의미를 사용합니다.
- 드로잉이 실제 검사 대상을 가리킵니다.
- Metric 차이가 검사 의도와 연결됩니다.
- 기준을 바꾸기 전에 잘못된 입력, ROI, 극성, template을 확인했습니다.
