# Screen glossary

| Term | Meaning |
| --- | --- |
| Image | The image to inspect |
| Main | Default Layer that holds the original image |
| Layer | Original, intermediate, or final result image |
| ROI | Image region to inspect |
| Tool | One processing or inspection function |
| PropertyGrid | Table that edits Tool parameters |
| Preview | Explicit one-time execution of the current Tool settings |
| Step | One Tool configuration saved in a Pipeline |
| Pipeline | Ordered Steps connected by Layer routes |
| Recipe | Saved unit containing a Pipeline and Tool settings |
| Metric | Decision value such as ResultCount, Area, Score, or Distance |
| Drawing/Overlay | Bounds, line, center, or ROI shown on the target |
| Run Review | Explicitly runs a saved Pipeline and reviews every Step |
| Good/Bad | Expected normal/abnormal role; not execution success/failure |
| WAIT | Normal state with no result from the current run yet |
