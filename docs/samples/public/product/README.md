# OpenVisionLab Product-Domain Samples

This folder contains public-safe product samples grouped by inspection domain.
Most images are deterministic synthetic assets generated by `tools/GenerateOpenVisionProductSamples.ps1`; the `field/` folder contains project-authored field-style review images normalized for the public product sample catalog. These assets are not copied from commercial SDK sample folders.

## Generation Standard

Product-domain samples are intentionally synthetic, but they should read like inspection images rather than flat toy drawings. The generator applies deterministic field variation to every product image: subtle GV drift, non-uniform illumination, light scan banding, sensor grain, and limited softness. Defects should remain explainable by metrics, but Good/Bad separation should not depend on exaggerated shapes or unrealistically clean backgrounds.

## Files

- `OpenVisionLab.ProductSampleManifest.csv`: source/provenance manifest for the generated assets.
- `../../OpenVisionLab.ProductSampleCatalog.csv`: runnable catalog with Good/Bad rows, expected metrics, and baseline pipelines.
- `Product_*.pipeline.xml`: baseline pipelines used by the catalog runner and sample picker.
- `templates/*.png`: generated template crops for matching-family samples.

## Regenerate

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\GenerateOpenVisionProductSamples.ps1
```

## Validate

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\RunVisionSampleCatalog.ps1 `
  -CatalogPath docs\samples\OpenVisionLab.ProductSampleCatalog.csv `
  -OutputDir artifacts\product_sample_catalog
```

Expected result: all 184 rows pass the catalog gate. The eighty-four Bad rows are expected-failure cases; they should produce controlled NG results with metric values inside the Bad ranges.

### Quality audit

After running the catalog, audit the Good/Bad separation before adding more rows:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\AuditProductSampleQuality.ps1
```

The audit reads the latest product catalog summary, compares each PairGroup by expected metric ranges, and adds a sampled image-difference heuristic. Use the review list to tune pairs that are too obvious, too subtle, or weakly separated by metric.
