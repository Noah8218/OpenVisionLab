# Proofline Pulse Design

## 1. 분위기와 시그니처

페이지가 아니라 작업 도구로 보이는 이슈 원장이다. 상단 컨텍스트 바에 제목, 전역 검색, 폴더 조작, 테마 조작을 모으고 아래에는 상태 탭과 이슈 목록을 바로 둔다. 큰 제목 영역, 소개 문장, KPI 카드, 장식 그림자는 없다. GitHub Issues의 검증된 목록 토폴로지와 Linear My Issues의 상태 그룹 밀도 위에 글래스모피즘의 반투명 표면·배경 blur·밝은 테두리·그림자 원칙을 적용한다.

콘텐츠 색상은 선택, 포커스, 위험도처럼 의미가 있을 때만 사용한다. 기본 단색 배경은 한 계열의 명암 그라데이션과 옅은 테마색 광원만 사용한다. 단색과 이미지 배경은 같은 글래스 불투명도·컨트롤 불투명도·백드롭 밝기를 공유하고 글자 팔레트는 선택한 라이트·다크 테마만 따른다. 네이티브 컬러 피커의 사용자 색상은 `--accent`, 텍스트 선택색, 배경 광원에만 반영하고, 위험도 색상은 테마와 분리된 고정 의미 팔레트를 사용한다. 상태는 색상과 한국어 텍스트를 함께 표시한다.

## 3. 타이포그래피

- UI 스택 `"Segoe UI Variable", "Noto Sans KR", "Segoe UI", sans-serif`
- 코드 스택 `"Cascadia Code", "SFMono-Regular", Consolas, monospace`
- `--type-context` 14px / 600 / 20px / -0.1px: 제품명과 현재 위치
- `--type-body` 14px / 400 / 20px / 0: 본문과 입력
- `--type-title` 15px / 600 / 22px / -0.1px: 이슈 제목
- `--type-label` 13px / 600 / 20px / 0: 탭과 그룹 헤더
- `--type-meta` 12px / 400 / 18px / 0: ID, 날짜, 보조 정보
- `--detail-line-height` 1.65: 펼친 상세 본문

## 4. 간격과 그리드

- 기본 단위 4px
- `--space-1` 4px, `--space-2` 8px, `--space-3` 12px, `--space-4` 16px, `--space-5` 20px, `--space-6` 24px, `--space-8` 32px
- `--layout-max` 1200px, `--detail-max` 832px, 데스크톱 여백 24px, 모바일 여백 12px
- `--context-height` 48px, `--connection-height` 44px, `--tabs-height` 40px
- `--control-height` 36px, `--group-height` 36px, `--issue-row-height` 56px
- `--radius-control` 8px, `--radius-list` 12px
- `--glass-blur` 24px, `--glass-saturation` 1.6, `--glass-brightness` 라이트 1.06 / 다크 0.92
- QA 폭은 390px, 768px, 1280px

## 5. 컴포넌트

- 컨텍스트 바: 최소 48px, `Proofline Pulse` 왼쪽, 전역 검색 중앙, 배경 설정과 컬러 피커 오른쪽. 다시 읽기·폴더 재지정·이미지 변경·테마 전환은 항상 고정 크기 아이콘으로 표시하고 설명은 툴팁과 접근성 이름으로 제공하며, 480px 이하에서만 제목·검색·조작을 세 행으로 분리
- 배경 설정: 조화로운 단색 명암 그라데이션을 기본으로 사용하고, 로컬 이미지를 선택하면 현재 대시보드 주소별 IndexedDB에 보존하며 이미지 모드에서 교체 버튼을 표시
- 폴더 연결 바: 초기 설정·권한·오류처럼 조치가 필요할 때만 표시하고 정상 연결 상태에서는 숨김
- 보기 도구막대: 상태 탭은 왼쪽, 상태·위험도·정렬은 오른쪽의 같은 수평선에 배치한다. 상태 탭은 아이콘과 수치만 사용하고 세 필터는 남은 폭을 같은 비율로 사용해 한 줄 전체를 채운다
- 상태 탭: 40px, 전체는 중립 그리드, 활성은 저채도 앰버 활동선, 보류는 저채도 모브 일시정지, 완료는 저채도 세이지 체크 아이콘과 작은 수치를 표시한다. 선택 경계는 해당 아이콘 색을 재사용
- 필터 도구막대: 상태·위험도·정렬을 데스크톱에서 각 160px, 높이 36px로 배치하고 좁은 화면에서는 남은 폭을 3등분
- 이슈 그룹: 접을 수 있는 36px 헤더에 상태명과 수치, 그룹 사이 여백 없음. 별도 인디케이터 없이 작업 중·대기/보류·완료 제목에 탭과 같은 저채도 앰버·모브·세이지를 재사용하며, 중복되는 목록 제목 행은 두지 않는다
- 이슈 행: 요약과 상세를 한 장의 반투명 유리판으로 묶고, 데스크톱 ID 84px, 제목 가변, 위험도 64px, 날짜 88px, 펼침 24px
- 이슈 상세: 카드 자체의 24px 배경 blur를 공유하고 내부에는 얇은 명암층과 밝은 상단 경계만 추가한다. 최대 832px 읽기 폭, 발견 맥락과 다음 조치 2열, Markdown 본문을 바로 표시하고 근거는 기본 접힘으로 공간을 절약
- 빈 상태: 목록 컨테이너 안에서 현재 사실과 다음 조작만 표시
- 컨트롤 상태: hover는 `--surface-hover`, focus는 2px `--focus-ring`, disabled는 50% 불투명도

## 6. 모션

- `--duration-fast` 120ms
- `--ease-out` cubic-bezier(0.16, 1, 0.3, 1)
- 배경색, 경계색, 글자색, 불투명도만 전환한다.
- 펼침은 네이티브 `details` 동작을 사용하고 레이아웃 애니메이션을 만들지 않는다.
- `prefers-reduced-motion: reduce`에서는 전환 시간을 0ms로 만든다.

## 7. 깊이

단색 배경은 웜 뉴트럴 한 계열의 명암 그라데이션과 사용자 선택 테마색을 옅게 겹쳐 유리가 흐릴 대상을 만든다. 이미지 배경은 중앙 정렬한 사진을 화면에 맞춰 채우고 테마별 오버레이만 더한다. 라이트 모드는 밝은 유리층으로, 다크 모드는 어두운 유리층으로 같은 배경을 다르게 통과시킨다. 상태 탭·컨트롤·이슈 카드는 균일한 반투명 표면, 24px blur, 160% saturation, 모든 면이 같은 1px 중성 경계, 얕은 그림자를 함께 사용하고 인공적인 방향성 흰 반사는 넣지 않는다. 펼친 본문은 별도 유리판을 중첩하지 않고 같은 카드 재질을 공유한다. 표와 코드 블록은 가독성을 위해 불투명하게 유지한다.

### 금지 규칙

- 큰 H1 영역과 소개 문장 금지
- KPI 요약 카드 금지
- 상태마다 채운 배지와 장식용 점 금지
- 목적지가 없는 사이드바와 탐색 항목 금지
- 외부 제품의 로고, 아바타, 아이콘 복제 금지
